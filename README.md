# Rocky deckviewer / Frontir Grow v11

33 slides. Exacte slidebeelden, geen herbouw van typografie. PDF-download, overzicht, leesbare slidetekst, toetsenbord, swipe en fullscreen. Slide 6 bevat de live Framer-preview.

## Bijwerken
De PowerPoint blijft het bewerkbare origineel. Exporteer na wijzigingen de PDF en slidebeelden. Vervang de betreffende slide-XX.webp en thumb-XX.webp en werk titels en zichtbare tekst in deck.js bij. Plaats geen interne spreeknotities, bronbestanden of commerciële fontbestanden online.

## Publiceren
Deze map is de volledige website. GitHub Pages: Settings > Pages > Deploy from a branch > main > / (root). De website is publiek. noindex is een verzoek aan zoekmachines, geen toegangsbeveiliging.

## Bediening
Pijltjes: vorige/volgende. Home/End: eerste/laatste. O: overzicht. F: fullscreen. Escape: venster sluiten. Op telefoon horizontaal swipen over de slide. Een link met #6 opent direct slide 6.

Geen externe fonts, analytics of tracking. Alle slidebeelden en PDF laden vanaf dezelfde host. Alleen de expliciete previewlink opent Framer.
